# مشاركة مباشرة P2P — WebRTC + Node.js

> **مبرمج التطبيق: زروقي أحمد معاذ**  
> تطبيق ويب مفتوح المصدر لنقل الملفات مباشرة بين المتصفحات، دون رفعها إلى أي خادم.

تطبيق مشاركة ملفات **Peer-to-Peer**: خادم الإشارات (Node.js + Socket.io) يعرّف الطرفين ببعضهما فقط (SDP/ICE) — **الملفات تنتقل مباشرة بين المتصفحين عبر `RTCDataChannel`** دون المرور بالخادم أو تخزينه. الواجهة بتصميم Signal (Frosted privacy glass) من `DESIGN.md`: أبيض/أزرق شاحب، أزرار مفرّغة، عناوين Inter بوزن 800، وخط Cairo للعربية.

## التشغيل

```bash
npm install        # على Windows إن تعذّر npm: npm.cmd install
npm start          # ثم افتح http://localhost:3000
```

> WebRTC يتطلب سياقاً آمناً: `localhost` يعمل مباشرة؛ على أي نطاق آخر يُلزم **HTTPS/WSS**.

جرّب: افتح الصفحة في نافذتين/جهازين → أنشئ غرفة في الأولى → انسخ الرابط → الصقه في الثانية → اسحب ملفاً.

## البنية

| المكوّن | الدور |

| `server/index.js` | إشارات فقط: غرف UUID v4، كلمات مرور مجزّأة (scrypt)، تمرير offer/answer/ICE، حدود معدل ومحاولات، تدمير الغرفة عند الفراغ، تنظيف الغرف المنتهية |
| `public/index.html` | الواجهة: هيرو، إحصاءات، تطبيق، خطوات، أمان، مميزات، بطاقة المطوّر، تذييل |
| `public/js/app.js` | تقطيع 64KB، ضغط خلفي `bufferedAmount`، إقرارات أجزاء، إيقاف/استئناف، تشفير AES-256-GCM، سحب وإفلات، سرعة/وقت متبقٍّ، تحقق من الحجم النهائي |
| `public/lang/` | ترجمات `ar.json` / `en.json` — كل نصوص الواجهة |

| `public/icons/` + `public/css/icons.css` | **60 أيقونة SVG** خطّية مولّدة آلياً وتُلوَّن بـ `currentColor` |
| `scripts/build-icons.js` | مولّد الأيقونات: `npm run icons` |

## اللغات والخطوط

- العربية (RTL) افتراضياً والإنجليزية (LTR) — مبدّل في شريط التنقل، والاختيار محفوظ في `localStorage`.
- الخطوط: **Cairo** للعربية و**Inter** للإنجليزية (Google Fonts، ومسموح بها في CSP).
- لإضافة لغة: انسخ `public/lang/en.json` وترجم القيم، ثم أضف رمزها إلى `SUPPORTED` في `public/js/i18n.js` وإلى قائمة `#lang-select`.

## الأيقونات

- جميع الإيموجي استُبدلت بأيقونات SVG خطّية في `public/icons/` (60 أيقونة: lock, shield, rocket, fingerprint, server, wifi, key, fire, …).
- تُستخدم في HTML كـ `<span class="icon i-lock"></span>` وتأخذ لون النص تلقائياً عبر CSS mask.
- لتعديل/إضافة أيقونة: عدّل `ICONS` في `scripts/build-icons.js` ثم `npm run icons`.

## الأمان (مقابل الثغرات الشائعة)

1. **حقن/استهلاك ذاكرة:** `MAX_FILE_SIZE` (افتراضي 2GB) + تحقق صارم من البيانات الوصفية (`name/size/chunks`) + رفض أي جزء أكبر من 64KB + التحقق من الحجم النهائي عند الاستلام + حد 64KB لحمولة الإشارة (`maxHttpBufferSize`).
2. **تسرّب IP عبر ICE:** STUN افتراضياً؛ للإخفاء اضبط TURN: `TURN_URL/TURN_USERNAME/TURN_PASSWORD` (تُحقن عبر `/config.js` بلا تخزين مؤقت).
3. **MitM على الإشارات:** انشر خلف HTTPS/WSS + DTLS/SRTP مدمج + طبقة AES-256-GCM اختيارية بمفتاح مشتق (PBKDF2) من رمز الغرفة وكلمة المرور — شاركهما خارج التطبيق. عند تفعيل التشفير دون كلمة مرور، يولّد التطبيق مفتاحاً عشوائياً قوياً ويعرضه للمشاركة (بدل اشتقاق مفتاح من رمز عام).
4. **اختطاف الغرفة:** رموز UUID v4، كلمة مرور مجزّأة بـ scrypt ومقارنة زمن-ثابت، حد لمحاولات الانضمام (10 محاولات/5 دقائق لكل IP)، سقف `MAX_ROOMS`، والغرفة تُدمَّر فور مغادرة آخر جهاز وتُنظَّف بعد `ROOM_TTL_MS`.
5. **أمان الخادم:** رؤوس CSP/COOP/Permissions-Policy/HSTS (في الإنتاج)، `X-Powered-By` معطّل، `no-store` لـ `/config.js`، تحقق من أصل Socket.IO (`ALLOWED_ORIGINS`)، وحدود معدل منفصلة للإنشاء/الانضمام/الإشارة.
6. **أمان العميل:** تطبيق الترجمات بلا `innerHTML` (يدعم `<br>` فقط)، عرض أسماء الملفات بـ `textContent`، تحقق من رمز الغرفة قبل الإرسال، وتنبيه قبل مغادرة الصفحة أثناء نقل جارٍ.

### ملاحظة صريحة
تشفير AES طبقة إضافية فوق DTLS؛ المفتاح مشتق من كلمة المرور، لذا اختر كلمة مرور قوية وشاركها بقناة موثوقة. الغرفة ثنائية (طرفان) في هذا الإصدار.

## حدود معروفة بصدق

- الجلسة ثنائية (جهازان) — البث متعدد النظراء مسجَّل كخارطة طريق.
- الاستئناف يعمل عبر إقرارات الأجزاء داخل الاتصال نفسه (إيقاف/استئناف)، وتُعاد البيانات الوصفية تلقائياً بعد إعادة فتح القناة؛ إعادة اتصال كاملة بعد انقطاع الشبكة تتطلب إعادة تفاوض.
- تشفير AES مشتق من سرّ الغرفة المشترك: المنضم يجب أن يدخل كلمة المرور/المفتاح نفسه، وإلا يُرفض فك التشفير برسالة واضحة.
